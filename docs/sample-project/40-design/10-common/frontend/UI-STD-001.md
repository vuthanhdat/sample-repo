# UI-STD-001 — UI Interaction Standard

- PC-first/responsive policy theo project requirement.
- Table/list dùng paging hoặc virtualization theo data volume; không tải toàn bộ dataset mặc định.
- Loading, empty, validation, permission-denied và error states phải có chuẩn thống nhất.
- Form field, label, validation message và action semantics nhất quán.
- Accessibility: keyboard, focus, labels và semantic controls theo NFR.
- Screen design chỉ mô tả phần feature-specific, không lặp lại common interaction rules.
