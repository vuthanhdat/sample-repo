# DEP-001 — Deployment and Runtime Topology Design

Define deployable units, runtime topology, environment topology, configuration/secret boundaries, database migration coordination constraints, backward-compatibility expectations, health/readiness model and rollback/roll-forward architecture considerations.

This document describes **HOW the solution is physically/runtime arranged**. Concrete deployment steps and rollout procedures belong to `80-operations/deployment/`.

Deployment topology is project-wide unless a feature has a justified exception.
