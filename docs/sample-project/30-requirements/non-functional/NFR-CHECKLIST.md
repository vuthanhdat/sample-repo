# NFR Applicability Checklist

Mỗi category phải được đánh giá `Applicable` hoặc `Not Applicable + reason`.

| Category | Status | Requirement |
|---|---|---|
| Performance / Scalability | Applicable | `NFR-PERF-001` |
| Availability / Reliability / DR | Applicable | `NFR-REL-001` |
| Observability / Operability | Applicable | `NFR-OPS-001` |
| Usability / Accessibility | Applicable | `NFR-UX-001` |
| Maintainability / Modifiability | Applicable | `NFR-MNT-001` |
| Security / Privacy | Applicable | `SREQ-001` |
| Localization | Not Evaluated | — |
| Compliance | Not Evaluated | — |
| Offline operation | Not Evaluated | — |
