# Deliverables

Deliverable là output mà project yêu cầu solution thực tế phải có. Design mô tả deliverable; task implement; verification kiểm chứng.

```text
Requirement → Design → Deliverable → Task → Verification
```

Deliverable được group theo feature để dễ ownership, còn `00-lists/` là index tổng hợp theo output type.
