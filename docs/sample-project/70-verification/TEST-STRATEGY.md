# Test Strategy

Verification phải cover cả functional và non-functional requirements.

## Levels
- Unit: domain/application logic.
- Integration: database, messaging, external adapters.
- Contract: API/interface/event schemas.
- E2E: critical flow across applicable features.
- NFR: performance, reliability, security, usability/accessibility, architecture quality.

## Evidence
Mỗi Verification Run phải gắn target version/revision, executor, result và evidence URI/payload.
