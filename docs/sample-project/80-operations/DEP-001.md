# DEP-001 — Deployment Design

Define runtime topology, deployable units, environment configuration, secret injection, database migration order, backward-compatibility requirement, rollback/roll-forward strategy, health/readiness gates and deployment verification.

Deployment design is project-wide unless a feature has a justified exception.
